# 💻 DESAFIOS DE LIVE CODING COM JAVA

Repositório de estudos para praticar lógica de programação, algoritmos e estruturas de dados com Java, com foco em entrevistas técnicas e sessões de Live Coding.

Cada desafio está organizado em sua própria pasta, com o código-fonte e um README contendo o enunciado, exemplos, explicação da abordagem e orientações de execução.

Além de implementar uma solução funcional, cada desafio busca compreender:

* 🧠 O raciocínio utilizado para resolver o problema
* 🧩 A estrutura de dados ou técnica aplicada
* ⚡ Possíveis otimizações
* ⏱️ Complexidade de tempo e espaço
* 💬 Como explicar a solução durante um Live Coding

---

## 🎯 Objetivo

A prática de desafios de Live Coding ajuda no desenvolvimento de habilidades importantes para entrevistas técnicas:

* 🧠 Raciocínio lógico
* ☕ Programação em Java
* 📦 Estruturas de dados
* 🔄 Algoritmos
* ⚡ Otimização de código
* 📊 Análise de complexidade Big-O
* 🧩 Resolução de problemas
* 💬 Explicação do raciocínio durante a implementação

A proposta é evoluir gradualmente de problemas mais simples para técnicas e estruturas mais avançadas.

## Como executar

Use um **JDK 11 ou superior**, com o comando `java` disponível no terminal. Não há dependências externas para os desafios.

Na raiz do projeto, execute o arquivo do desafio desejado. Por exemplo:

```powershell
java "01 - First Unique Character/FirstUniqueCharacter.java"
```

As entradas dos exemplos ficam no método `main` de cada classe. Altere os valores, salve o arquivo e execute novamente. Os READMEs individuais também trazem o comando para execução dentro de cada pasta.


🧠 A proposta é compreender cada solução, analisar sua complexidade e praticar a explicação do raciocínio durante o live coding.
